# Reparatech - Evaluación Parcial 2

Desarrollo frontend de una tienda online interactiva, correspondiente a la Evaluación 2. 

 
 Equipo de Trabajo
* Thomas Marin
* Maximiliano Navarrete
* Dafne Vargas

##  Tecnologías y Herramientas Utilizadas
* **React:** Construcción de la interfaz de usuario mediante componentes reutilizables aplicando el principio de responsabilidad única.
* **Bootstrap:** Implementación de diseño responsivo adaptado para móviles, tabletas y escritorio.
* **JavaScript:** Gestión de persistencia de datos simulada mediante un archivo local con operaciones CRUD.
* **Jasmine y Karma:** Entorno de configuración para la ejecución de pruebas unitarias de los componentes.
##  Funcionalidades y Vistas Implementadas
El proyecto consiste en la migración de un template HTML estático a una arquitectura basada en React[cite: 1], incluyendo los siguientes flujos de navegación:
* **Tienda Pública:** Página principal, catálogo de productos, vistas filtradas por categorías, carrito de compras, y flujo de validación de pago (Checkout)
* **Panel de Administración (Dashboard):** Sistema de gestión integral para monitorear órdenes, inventario de productos, categorías y perfiles de usuario
* **Cobertura de Pruebas:** Validación técnica de renderizado condicional, manejo de *props*, cambios de *state* y simulación de eventos en la interfaz
